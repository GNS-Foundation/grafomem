Independent Certification Verifier

A funder can verify a certification’s signature here — directly, with no login and no access to the originating system. This page only calls two public endpoints: GET /v1/gcrumbs/verify/key and POST /v1/gcrumbs/verify.

1 · The certification receipt

“Generate” needs a demo tenant API key (below) — it certifies a sample invoice server-side and drops the signed receipt here. A funder would instead paste one they received.

2 · The signer’s public key

The real key is served at a public URL, no authentication. A wrong key must be rejected — that’s what binds the check to the true signer.

Running on GRAFOMEM Cloud (staging) · synthetic demo data · the mechanism, working. Signatures are Ed25519 over the receipt id; verification recomputes the id from the receipt’s own fields and checks the signature — no database access.
